# eFootball AI Coach

Landing page MVP para un AI Coach de eFootball Mobile.

## Requisitos

- Node.js 20+
- npm

## Ejecutar

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## Estructura

- `app/page.tsx` — página principal
- `app/globals.css` — estilos globales
- `components/SquadPreview.tsx` — mockup visual del XI
- `app/layout.tsx` — metadata y layout
